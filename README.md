## Project Overview

**AI Meeting Assistant** is an intelligent, AI-powered system designed to enhance meeting productivity by offering real-time transcription, summarization, and action item tracking. Leveraging a large language model (LLM), our AI agent interacts with users through natural language, streamlining meeting management and improving efficiency.

### Key Features
- **Real-Time Transcription:** Convert meeting audio to text on the fly.
- **Meeting Summarization:** Automatically summarize meeting discussions.
- **Action Item Extraction:** Generate and track action items for follow-up.
- **Multilingual Support:** Translate meeting content into multiple languages.
- **Transcript Interaction:** Extract full transcripts and interact via chat.
- **Database Management:** Maintain past meeting records using SQLite.
- **Agentic Meeting Management:** Create, update, delete, and monitor meetings and action items using AI.

We are **Team Tricon**, a group of three students from Ghulam Ishaq Khan Institute of Engineering Sciences and Technology, dedicated to revolutionizing meeting management with advanced AI capabilities.

## Technologies Used

### Frontend
- **React + TypeScript:** For building a robust and user-friendly interface.
- **Tailwind CSS:** For responsive and modern styling.

### Backend
- **Python (FastAPI):** For handling API requests with efficiency.
- **Uvicorn:** To serve the FastAPI application.
- **SQLite:** For lightweight and effective data storage.
- **LLM-based AI Agent & Generative AI:** For intelligent conversation, summarization, action item extraction, and contextual suggestions.

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites
Ensure you have the following installed on your system:
- **Python 3.9+**
- **Node.js & npm** (for the frontend)
- (Optional) **Virtual Environment** for Python dependencies

---

### Backend Setup

1. **Clone the Repository**
2. Run the frontend with npm
```bash
npm run build

```
3. **Run the backend server through uvicorn
```bash
uvicorn backend:app --reload

```
